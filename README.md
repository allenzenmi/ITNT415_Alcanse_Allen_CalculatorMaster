## Project Description
Calculator Master is a menu-driven Python calculator built to demonstrate
Git branching, source code management, and GitHub collaboration workflows.
The project began as a skeleton on the `main` branch, with each arithmetic
operation (addition, subtraction, multiplication, division) developed on
its own feature branch, committed, and merged back into `main` through
Pull Requests. The final version integrates all four operations into a
single, menu-driven application with input validation and error handling.

## Branch Structure
- `main` — integrated final calculator
- `addition_Alcanse` — implements the addition operation
- `subtraction_Alcanse` — implements the subtraction operation
- `multiplication_Alcanse` — implements the multiplication operation
- `division_Alcanse` — implements the division operation, including
  division-by-zero handling

## Program Features
- Menu-driven interface (Addition, Subtraction, Multiplication, Division, Exit)
- Input validation — re-prompts the user on non-numeric input
- Continuous execution — keeps running until the user chooses to exit
- Proper function definitions for each arithmetic operation
- Error handling for invalid entries
- Division-by-zero handling with a clear error message
